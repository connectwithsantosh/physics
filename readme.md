# Quantum ESPRESSO Learning Project

This repository contains my beginner-level work and experiments while learning **Quantum ESPRESSO** and computational materials science.

The project is not structured as a production-ready or professionally maintained Quantum ESPRESSO repository. Files and calculations are currently organized as I learn and experiment with different examples.

## Learning Examples

The repository currently contains examples and experiments involving:

* **Hydrogen (H₂)**
* **Ammonia (NH₃)**
* **Sodium (Na)**
* **Methane (CH₄)**
* **Pseudopotentials**

These examples are being used to learn how to:

* Create Quantum ESPRESSO input files
* Define atomic structures
* Work with pseudopotentials
* Perform basic DFT calculations
* Understand calculation parameters
* Run calculations on Ubuntu Linux
* Read and interpret output files
* Experiment with different materials and molecules

## Current Status
